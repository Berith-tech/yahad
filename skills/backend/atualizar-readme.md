# Skill: Atualizar README.md

Atualize o `README.md` da raiz sempre que uma das situações abaixo ocorrer:

- Novo endpoint criado ou removido
- Nova tabela ou migration aplicada
- Nova dependência adicionada ao `.csproj`
- Mudança nos passos de setup local
- Qualquer coisa que impacte como outro dev (ou outra IA) entende ou sobe o projeto

## O que atualizar

Atualize **somente as seções afetadas**. Nunca reescreva o documento inteiro.

As seções que devem se manter vivas:
- Stack e versões
- Como subir o ambiente (pré-requisitos, configuração, migrations, comandos)
- Endpoints disponíveis
- Schema do banco
- Status do projeto (o que está pronto, o que está pendente)

## Regra

Documente apenas o que já está implementado e funcional. Nunca antecipe features futuras no README.
